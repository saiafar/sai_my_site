Answers are drawn from the same knowledge base consulted by the site's assistant,
and each statement links to the supporting document. If what you're looking for
isn't here, ask the assistant directly on the home page.

## How is this personal website and RAG assistant built?

This website is a production platform with an integrated RAG (Retrieval-Augmented Generation) assistant that answers questions in natural language grounded strictly in its markdown knowledge base [1](/en/proyectos/sitio-personal-rag). It uses Next.js with React 19, PostgreSQL with pgvector and full-text search combined via Reciprocal Rank Fusion (RRF), local embedding generation with Xenova/multilingual-e5-small, and Gemini 2.5 Flash for response generation [1](/en/proyectos/sitio-personal-rag).

## What experience do you have with databases and search systems?

I have extensive experience working with relational databases, predominantly PostgreSQL, MySQL, and MariaDB [1](/en/perfil/rafaias-villan). In recent systems, I have implemented hybrid search combining semantic vector search using pgvector with lexical full-text search with language-specific stemming and reciprocal rank fusion [1](/en/proyectos/sitio-personal-rag).

## What have you done with artificial intelligence and automation?

I have also built end-to-end automation workflows connecting CRMs, email inboxes, and external APIs with n8n to streamline operations [1](/en/perfil/rafaias-villan).
